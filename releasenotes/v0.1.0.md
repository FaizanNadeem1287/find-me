# Find-Me v0.1.0 — Initial Official Release

Welcome to the initial official release of **Find-Me**, an offline-first, high-performance Linux desktop search engine written in 100% pure Rust, featuring a modern GPU-accelerated Iced GUI.

---

## Highlights & Features

### 🚀 Ultra-High Performance Core Engine
- **Compact 32-Byte FileRecord Arena**: Indexes 1,000,000 files in under 45 MB of RAM using hierarchical directory deduplication and continuous string interning.
- **Parallel Filesystem Crawler**: Saturates multi-core NVMe/SSD I/O with `jwalk` + Rayon, indexing over 200,000 files/sec unprivileged.
- **Real-Time Linux inotify Monitoring**: Zero polling required; kernel-level inotify notifications debounced at 150ms with queue overflow recovery.
- **Zero-Copy Persistence**: Binary cache disk format with SIMD CRC32 integrity checks, loading 1,000,000 files in <35 ms on startup.

### 🔍 Search Grammar & Matching Engine
- **Everything Query Syntax**: Native support for filters (`ext:`, `size:`, `dm:`, `path:`, `regex:`, `attrib:`, boolean operators `AND`, `OR`, `!`, and wildcards `*`, `?`).
- **Hybrid Search Matching**: Fast exact substring matching by default, with `nucleo-matcher` fuzzy fallback and SIMD predicate evaluation.
- **Headless CLI & Multi-Format Exporter**: Run queries from terminal (`find-me --query <pattern> --json`), pre-fill GUI on boot, and export results to CSV, TXT, or EFU (Everything File List).

### 🧠 Local Semantic Vector Search & Content Extraction
- **Deep Document Extraction**: High-throughput extractors for PDF, CSV, Excel (`.xlsx`, `.xls`), PowerPoint (`.pptx`), Word (`.docx`), plain text, and code files.
- **On-Device Quantized Embeddings**: Zero cloud dependency; local `all-MiniLM-L6-v2` embedding model.
- **Persistent HNSW Vector Store**: Cosine similarity index + SQLite chunk store for semantic document discovery.
- **Multimodal AI**: Offline Whisper speech-to-text audio indexing and CLIP vision embeddings.
- **Reciprocal Rank Fusion (RRF)**: Blends exact lexical matching with semantic dense vectors for optimal relevance.

### 🎨 Desktop Integration & Ergonomics
- **Modern Iced GUI**: Elm architecture with virtualized table rendering 100,000+ files locked at 60 FPS.
- **FreeDesktop Standards**: DBus `FileManager1` file highlighting, XDG autostart, and system dark/light theme sync.
- **Universal Packaging**: Debian `.deb` package, standalone portable `.AppImage`, Arch Linux AUR `PKGBUILD`, and Flathub-ready Flatpak manifest.

### Installation Instructions

#### Debian / Ubuntu (`.deb`)
```bash
sudo dpkg -i find-me_0.1.0-1_amd64.deb || sudo apt-get install -f -y
```

#### Standalone AppImage
```bash
chmod +x find-me-0.1.0-x86_64.AppImage
./find-me-0.1.0-x86_64.AppImage
```

#### Manual Extraction
```bash
tar -xzf find-me-v0.1.0-x86_64-unknown-linux-gnu.tar.gz
cd find-me-v0.1.0-x86_64-unknown-linux-gnu
./find-me
```
